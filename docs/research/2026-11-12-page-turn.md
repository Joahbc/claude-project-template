# Page-turn interactions for a book-like site

Status: **research** (untested). Checked 2026-11-12. For: Dariia Taradai's site, where the two sections (drawings, paintings) read like printed art catalogues: white space, small captions, page numbers, image and text spreads.

## Requirements
- Every spread or artwork has its own URL
- Arrow keys, swipe, and visible focus
- Reduced motion: a fade or a flat layout
- Single pages on phones
- Readable without JavaScript

## The base, whatever the turn looks like
Every spread is a real HTML page (an Astro route per spread or artwork) with real links to the previous and next page. The turn is an enhancement on top. With JavaScript off, or with reduced motion, it's a normal page change.

## Options

| Approach | Feel | URLs, no-JS | Keyboard, swipe, reduced motion | Effort |
|---|---|---|---|---|
| **Cross-document view transitions** (`@view-transition { navigation: auto; }` plus custom keyframes) | Animated turn between real pages | Native: it's navigation | Arrow keys and swipe need a small script; reduced motion is a media query | Low. Chrome 126+, Edge, Safari 18.2+; Firefox partial (normal page load instead) |
| **CSS 3D + GSAP** (rotateY on a hinge, shading to fake the curl) | Rigid page with light, can feel very physical with good easing | Yes, as an enhancement | Fully under our control | Medium |
| **Page-flip libraries** (StPageFlip and its React wrapper `react-pageflip-enhanced`, turn.js) | Soft, realistic curl, quick to get | Fights it: all pages sit in one container, so URLs need custom history sync | Weak or missing; turn.js needs jQuery and has licence limits for some uses | Low to start, high to make accessible |
| **WebGL page curl** (three.js shader on a subdivided plane, e.g. `turngl`; R3F `@objectifthunes/react-three-book`) | Most beautiful: real bend, light and shadow | Only as a layer over real HTML | Everything added by hand; artwork photos become textures (check colour accuracy) | High |

## Recommendation
- Real HTML spreads always
- In Dariia's Explore step, prototype three turns and let her and Joah choose by feel: view transitions, CSS 3D + GSAP, and a WebGL curl
- Libraries only as a quick spike to feel the soft curl, never as the base
- On phones: single pages, swipe, and probably a simpler turn (slide or fade); decide in Explore

## To test before promoting
- [ ] Each prototype with keyboard only, a screen reader, swipe on a real phone, reduced motion and JavaScript off
- [ ] Frame rate on the mid-range phone profile (4x CPU throttling)
- [ ] Artwork colours in WebGL compared with the same image as `<img>`
